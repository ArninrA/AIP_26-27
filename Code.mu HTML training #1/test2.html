What is CMS?

CMS - "Content Managment System(engine)" - a foundation for a website written by PHP programmers, with which you can manage the website(add content, change menu items, etc.) without knowing HTML and CSS

However, in order to make website using CMS you will need the services of programmer, a designer, and a layout designer. And capital investments

What types of CMS are there?

There are different content management systems: for online stores, for blogs, for forums and so on.

Examples of CMS

Examples of popular CMS: Joomla, WordPress(for blogs), PhbBB(for forums).

CMS-ki can be paid and free.
