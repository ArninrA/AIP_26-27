PHP and JavaScript

The programming languages PHP and JavaScript allow you to make a site dynamic, i.e. responsive to user actions. For example, you can make a beautiful drop-down menu or slider.

Types of scripts

For this purporse, scripts are written (English script - script) - programms that allow you to respond to user actions. There are two types of scripts:

  • those that are executed on the server, and the result of their execution comes to the user's browser in a ready-made form. These is scripts written in the PHP language. CMS-ki are written in it - content managment systems.
  • those that are executed directly in the user's browser. These are scripts written in JavaScript language. They are most often used to make the page more convenient and beutiful.
